# Theme Switcher

You have 6 versions of the website saved in this project:

1. **v1** (`v1_bland`): The original, basic starter template.
2. **v2** (`v2_dark_luxe`): The Dark Luxe theme (Black, charcoal, gold, Geist font).
3. **v3** (`v3_royal_italian`): The Royal Italian theme (Deep Emerald green, beige, gold, Playfair Display).
4. **v4** (`v4_marble_cream`): The Light Marble theme (Bright marble background, Playfair Display).
5. **v5** (`v5_imperial_depth`): Imperial Housing rebranding with elegant fonts (Cormorant Garamond & Montserrat) and enhanced 3D glass depth.
6. **v6** (`v6_imperial_marble_bg`): Imperial Housing with the high-resolution luxury marble photograph background (Current Active).

## How to show them to your client

You don't need to stop your server or open different ports! Because Next.js automatically hot-reloads changes, you can just swap the files and the browser will instantly update while you're presenting.

To switch themes, open a new terminal in this folder (`D:\JAYESH-interior web`) and run the script:

```powershell
.\switch_theme.ps1 v2
```

*(Replace `v2` with whatever version you want to show: `v1`, `v2`, `v3`, `v4`, `v5`, or `v6`)*

Your client will see the website instantly transform right before their eyes in the browser!
